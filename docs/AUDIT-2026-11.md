## 1. Rezumat executiv

Site personal, necomercial (CV + portofoliu), fără conturi pentru vizitatori, fără plăți, fără analiză de trafic. Suprafața de atac
reală: formularul de contact, autentificarea administratorului, API-ul public Supabase (cheie publishable) și încărcarea de fișiere în admin.

Au fost găsite **0 vulnerabilități critice**, **1 înaltă** (brute force distribuit pe login — **FIXED**), **2 medii** (MFA admin
neaplicat, spam distribuit pe formular — **FIXED**) și mai multe probleme scăzute/de conformitate, majoritatea **FIXED**. Rămân
de făcut acțiuni externe (DNS SPF pe apex, rotirea unei chei expuse în chat, revocarea accesurilor temporare, activarea
evenimentelor de deployment Vercel → GitHub, MFA efectiv activat de proprietar).

## 16. Configurare externă necesară

1. **DNS (Google Cloud DNS, zona `ciupitustefan-com`)**: adaugă `TXT` pe apex `ciupitustefan.com.` cu valoarea `v=spf1 -all`. După 2–4 săptămâni de rapoarte fără probleme, poți trece DMARC de la `p=none` la `p=quarantine`.
2. **Vercel → Settings → Git**: activează crearea de GitHub Deployments / evenimentele `deployment_status`, ca `post-deploy.yml` (smoke tests + OWASP ZAP) să ruleze automat.
3. **Supabase**: rotește cheia secretă (creezi una nouă → o pui în Vercel → redeploy → ștergi cheia veche); opțional, plan Pro pentru HIBP și backup-uri cu restaurare la moment.
4. **Backup**: planul Supabase Free nu oferă backup descărcabil verificat — fă un export lunar (`docs/OPERATIONS.md` §2). **[NOT VERIFIED]** backup automat.
5. **GitHub**: protecția branch-ului `main` (`docs/CI-CD.md` §6).

## 17. Acțiuni manuale pentru proprietar

1. **Activează MFA**: Admin → Securitate → „Activează verificarea în doi pași”.
2. Activează MFA și pe conturile **Vercel, Supabase, Resend, GitHub și Google** (domeniu + DNS).
3. **Revocă accesurile temporare** din această sesiune: Google („Google Cloud SDK”), Supabase (`claude-cloud-session`), Vercel (token CLI), Resend (autentificarea CLI cu acces complet).
4. Rotește cheia secretă Supabase (punctul 16.3).
5. Acceptă DPA-urile furnizorilor (Vercel, Supabase, Resend).
6. Opțional: revizuire juridică a politicilor de confidențialitate și cookie-uri.
